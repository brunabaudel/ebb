M · Settings-style rows

Zero pills on the main screen — drill in

iOS Settings pattern: each field is a row showing current value (or “Not set”). Tap row → push or sheet with that field’s control. Main screen is ~10 rows, very scannable.

Very familiar on iOS Shows what’s filled at a glance Extra navigation per field

N · Build from empty

Start blank — add only what matters

Inverse of the current form: screen starts empty. Tap “+ Headache”, “+ Period”, “+ Triggers” to add categories. Each becomes an editable chip; tap chip to open its fields. Nothing you don’t ask for.

Zero noise for minimal logs Grows with user intent Discoverability of “+ Period” etc.
