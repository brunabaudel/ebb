UI Design · Visual Mockup

A health tracker you can talk to — built calm enough to use mid-migraine.

Working name “Ebb” (placeholder — it’s the estrogen ebb that triggers the attack). Every screen is designed dim-first because the person logging is light-sensitive and low-energy. Coral carries the pain axis, lavender the cycle axis. Non-functional mockup — visual design only, no implementation. See also: 18 broader calendar directions · month & week design pairs.

Calendar placement (not in tab bar): Keep the tab bar to Today · Patterns · Settings — three destinations, not four. Calendar is history browsing; open it from Today via the calendar icon in the header (or tap the date). It pushes on the Today stack with a back button — same month/week views as before, tab bar stays on Today underneath.
