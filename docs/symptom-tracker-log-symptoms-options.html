Log symptoms · UI exploration

Less button soup, same schema.

Seven directions for the tap-logging sheet — all using the same fields from symptom-schema.json, all still optional. The goal: calmer mid-migraine, fewer decisions on first glance.

The crowding problem: With migraine expanded, the current screen shows ~60 tappable pills across 12 fields. Every enum value is visible at once — correct for completeness, exhausting when your head hurts.

More in part 2 · Combined pick: I + L + J + K merged ★
