Today · Talk entry points

Put Talk on Today — sixteen ways.

Today currently opens logging via + only; Talk lives inside that flow. These mocks explore making Talk a first-class action on Today, still with Tap/+ available. Plum & Ember tokens.

Constraints

  • Keep calendar ▦ and + for manual log
  • Talk should be reachable in one tap
  • Migraine-friendly: large hit target, low clutter
  • Tab bar stays Today · Patterns · Settings

What varies

  • Floating vs inline vs header
  • Talk alone vs Talk + Tap pair
  • Always-visible vs empty-state only

  • Luteal · day 24
