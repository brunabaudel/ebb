Same two views, different designs

Every option keeps the Month and Week toggle — only layout, encoding, and detail placement change. Companion board: 18 broader calendar directions · SF Symbol entry icons.

How to read this board: Each row is one design direction shown twice — month on the left, week on the right. Toggle always switches between the same two modes. Start with Design 00 — compact month + Today-style history (matches the Today tab entry rows).
Design 00 · recommended
Compact month + Today-style history
Shorter grid (30px cells, tighter gaps) so the history section gets more room. Entries match Today — flat rows with accent dot, title + time, description, severity bar, and marker chips — not the old emoji cards. Same pattern in week view.
