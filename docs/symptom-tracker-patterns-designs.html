Patterns tab · design board

Seven ways to show cycle insights.

Layout and hierarchy explorations for the Patterns tab. All options use the same data (timeline, triggers, insight, relief) and Plum & Ember tokens. The app ships Today · Patterns · Settings — three tabs only.

Current implementation reference → symptom-tracker-patterns-mocks.html

Shared content

  • Top triggers: Poor sleep (3), Stress (2), Skipped meal (1)
  • Insight: poor sleep in luteal window
  • Relief: Ibuprofen 50%, Sumatriptan 100%

Constraints

  • Synthesis only — no log history
  • Dim-first, low luminance
  • Warm = pain, cool = cycle
  • Deterministic stats, template copy

Evaluation lens

  • Scannable during a migraine?
  • Does luteal clustering read instantly?
  • Room for 1–4 triggers + 2–3 meds?
