Merged concept · I + L + J + K

Talk, pre-fill, one question, read it back.

Combines pattern shortcut (L), one-question focus (I), live sentence preview (J), and body map + slider (K) into a single logging flow. Same schema — just a calmer path through it.

Implementation notes

Step order is fixed but skippable: Headache → Severity → Location → Quality → Cycle/Context → Review. If migraine = No, skip to Cycle/Context.

L only shows when PatternStatsEngine has ≥2 similar entries in the current cycle phase. Otherwise Step 0 is just Talk + Start blank.

J sentence strip maps 1:1 to schema fields — tapping “right side” opens Step 3 (location map).

K map writes the same location multi_enum keys as pills would. Slider writes severity scale 1–5.
